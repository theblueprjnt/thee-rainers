# Rainers · Voice Guides

How I write across different contexts. Five reference docs, one per surface.

The hard rules (banned punctuation, banned words, locked names) live in `.claude/skills/trb-voice/SKILL.md` and apply everywhere. These guides cover the **register** — how the same voice flexes between contexts.

## The files

- [website.md](./website.md) — landing pages, product copy, sales pages
- [emails.md](./emails.md) — broadcasts and one-to-ones
- [social.md](./social.md) — Instagram, TikTok, YouTube captions and Reels copy
- [informal.md](./informal.md) — DMs, replies, voice notes
- [communication.md](./communication.md) — general principles that govern all of the above

## Core voice (one register, five flavours)

Owner-grade. Calm. Objective. Diagnoses better than the reader can. Physical language — what the movement does to the fighter. Short, declarative, period-ended. Substance under every claim. Faith woven, never preached.

The five surfaces above are not five different voices. They are the same voice at different distances from the reader: a public sales page is colder than a DM reply, but neither sounds different from the same person.

## How to use these files

When writing copy for a new surface:
1. Open the relevant guide (e.g., `social.md` for an Instagram caption)
2. Check the *Do* and *Don't* sections for that register
3. Use the example bank as raw material — the patterns are observed from real Rainers copy that converted
4. Run the result through `.claude/skills/trb-voice/SKILL.md` (banned punctuation, banned words, locked names)

## Filling these in

Each file has `[RAINERS]` markers where I need to add real examples — texts I have written, emails that landed, captions that performed. The skeletons capture what I can observe from the site copy. The personal voice flavour comes from those examples.
